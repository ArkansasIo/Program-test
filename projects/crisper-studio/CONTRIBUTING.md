# Contributing

Thanks for helping improve CRISPER Studio.

## Development

1. Use Node.js 20 or newer.
2. Install dependencies with `npm install`.
3. Run `npm test` and `npm run build` before submitting changes.
4. Keep DNA utilities deterministic and covered by unit tests.
5. Validate data at UI and IPC boundaries; use parameterized SQL.
6. Do not describe illustrative scores as validated biological predictions.
7. Avoid committing real, patient-identifiable, or confidential sequence data.

## Pull requests

Describe the behavior changed, tests run, and any known limitations. For UI changes, include a screenshot when useful. Never claim checks passed unless you have observed their results.
